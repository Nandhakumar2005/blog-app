# 🚀 Installation

## Clone the repository

```bash
git clone https://github.com/Nandhakumar2005/blog-app
```

## Move into the project

```bash
cd Blogzera
```

## Install dependencies

```bash
npm install
```

## Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
